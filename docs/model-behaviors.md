# 模型输出偏差观察

在实际中文编程协作与技术汇报场景中，不同主流模型在“不说人话”上往往呈现出不同的高频偏差。以下总结基于实际使用观察，用于决定专项提示词的强调方向，不代表对模型底层训练机制的因果断定。

| 模型系列 | 高频输出偏差 | 对应专项文件 | 纠偏重点 |
| :--- | :--- | :--- | :--- |
| **GPT / Codex** | 默认读者看过全部上下文、均质短判断句连发、定位细节堵塞主干、内部代号直接当结论 | [`profiles/gpt-codex.md`](../profiles/gpt-codex.md) | 脱离上下文翻译成外部行为、补全句间逻辑衔接、定位证据后置 |
| **Grok** | 过度压缩成电报体、连接词与主语缺失；一旦放松约束又容易滑向网络梗与表演式口语 | [`profiles/grok.md`](../profiles/grok.md) | 保留必要连接词与正常省略边界、把状态机翻译成行为语言、禁止耍贫嘴 |
| **DeepSeek** | 刻意熟络的伪人口语、莫名其妙的比喻与自造黑话、双引号/冒号/破折号及列表表格滥用 | [`profiles/deepseek.md`](../profiles/deepseek.md) | 保持克制书面直白体、封杀装饰性比喻、克制引号与强行排版 |

其他开源或通用模型（如 Llama、Mistral、Qwen、GLM 等）常见的**英文直译腔**与**公文申论八股腔**已统一收归 [`profiles/general.md`](../profiles/general.md) 处理，不再单独划分模型集合。
